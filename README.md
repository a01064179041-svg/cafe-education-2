# 카페교육 2 프로젝트 백업

노트북에서 작업을 이어가기 위한 대화 기록과 프로젝트 자료입니다.

## 포함 자료
- conversations/: 이 프로젝트 폴더에 연결된 대화 3개의 사용자·assistant 텍스트 기록
- 마케팅커뮤니케이션_9월10일_녹음정리.md: 강의 녹음 정리
- marketing_transcript.jsonl: 강의 자동 전사

대화는 2026년 10월 26일 백업 시점까지 저장했습니다. 도구 실행 기록, 시스템 지침, 첨부파일 원본, 앱의 내부 대화 상태는 포함하지 않습니다. 대화 파일은 읽거나 새로운 대화에 참고자료로 제공할 수 있습니다.

## 확정된 PPT 일정
- 10월 28일 오후 11시 59분: PPT 초안 완성 및 카톡방 공유
- 10월 29일 오후 11시 59분: 본인을 제외한 모든 조원 슬라이드 피드백을 양식에 맞춰 카톡방에 작성
- 10월 31일 오후 11시 59분: 받은 피드백을 참고하여 PPT 수정·퇴고 후 공유
- 11월 1일 오후 10시 30분: 조별 회의 시작

피드백 공지와 최종 복사용 양식은 10월 24일 대화 파일에 있습니다. 별도 수정본 제출 양식은 삭제했습니다.
